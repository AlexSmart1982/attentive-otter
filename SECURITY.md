# Reporting security and data integrity issues

For a possible security issue or a defect that could affect file integrity, contact **alexsmart@yandex.ru**. Include the exact release version, operating system, steps to reproduce and whether an application transaction was interrupted.

Share a synthetic example where possible. Public issues and logs can expose local paths or photo metadata; remove private details before posting. The beta's journal and saved comparison may be useful for diagnosis, but they should be reviewed for private information before sharing.

Ordinary usability bugs and feature requests can be filed in [GitHub Issues](https://github.com/AlexSmart1982/attentive-otter/issues).
