# Ограничения текущей beta-версии

## Платформы

Доступны Windows x64 и отдельные macOS arm64/x64 сборки. macOS-сборки требуют macOS 14+, проверяются на macOS 15 и используют техническую подпись без Apple Developer ID/нотариального заверения.

В macOS блокировки файлов рекомендательные: другая программа может их не учитывать. На время применения закройте программы, изменяющие тот же архив. Проверки identity и SHA256 выполняются перед файловыми действиями, но абсолютной защиты от произвольных конкурентных изменений нет. Системная корзина вызывается через NSFileManager, без постоянного удаления при отказе. [Подробнее](MACOS.md).

## Даты

При отсутствии EXIF `DateTimeOriginal` текущий экспорт может записать EXIF `DateTime` в поле, показанное как «Съёмка». `DateTime` может относиться к обновлению изображения или метаданных. Для проверки источника откройте полный EXIF; не считайте такое значение гарантированной датой съёмки.

В режиме «Съёмка → создание → изменение» используется первое доступное значение. При одинаковой дате EXIF даты Windows не разрывают равенство. Даты Windows описывают экземпляр файла; они не устанавливают истинную дату съёмки.

## Похожесть и рекомендации

Внутренний score сравнения не является вероятностью совпадения или измеренным процентом визуального сходства. Подходящая граница зависит от архива. Рекомендации следуют выбранному порядку критериев, а окончательное решение принимает пользователь.

Количество байтов само по себе не доказывает, что файл содержит больше исходных деталей: пересохранённый JPEG может оказаться больше источника.

## Большие группы

Для плотных наборов взаимно похожих изображений число пар может расти квадратично. Экспорт сохраняет список пар в памяти и в JSON. Реальное использование на архиве из 84 000+ изображений не подтверждает работу любого набора такого размера или архива из миллиона файлов.

## Сохранения и применение

Сохранённые сравнения используют абсолютные пути к изображениям. Перемещение архива сторонним приложением может сделать эти пути недоступными.

Undo/redo относятся к решениям до применения. После применения файлы уже перемещены в выбранное место или корзину; история решений не является способом отменить выполненный batch. Журнал восстановления предназначен для незавершённой транзакции.
