## Комплект этого релиза

[Релиз v1.0.0-beta.1](https://github.com/AlexSmart1982/attentive-otter/releases/tag/v1.0.0-beta.1) содержит:

- `Attentive_Otter_1.0_BETA_Windows_x64.zip` — готовое приложение, LICENSE, COPYRIGHT.txt и уведомления зависимостей.
- `Attentive_Otter_1.0_BETA_Corresponding_Source.zip` — соответствующий снимок кода, ресурсы, скрипты, зафиксированные зависимости, их исходные архивы, лицензии и отчёты проверки.
- `SHA256SUMS.txt` — контрольные суммы архивов.

Для этого Windows EXE используйте именно комплект исходников этого тега. Автоматические архивы **Source code** на GitHub содержат дерево репозитория, но не полный набор исходных архивов сторонних компонентов. Детали происхождения: [RELEASE_PROVENANCE.md](RELEASE_PROVENANCE.md).

## Сторонние компоненты

Для [macOS beta.2](https://github.com/AlexSmart1982/attentive-otter/releases/tag/v1.0.0-beta.2) опубликованы отдельные бинарные и Corresponding Source ZIP для arm64 и x64. Они содержат Qt 5.15.17, PyObjC (MIT), исходники зависимостей, рецепты сборки, notices и свои `third_party/sources.json`. macOS использует собственную сборку OpenCV без FFmpeg; строки FFmpeg/pywin32 ниже относятся к Windows beta.1. При распространении Mac-версии используйте соответствующий ей комплект источников, а не Windows Source ZIP.

Приведённая таблица — краткая навигация по комплекту. Полные тексты, исключения и уведомления находятся в [third_party/licenses](../third_party/licenses), а точные версии, URL и SHA256 исходников — в [sources.json](../third_party/sources.json).

| Компонент | Основная лицензия в текущем комплекте |
| --- | --- |
| Python | PSF и уведомления встроенных компонентов |
| PyQt5 | GPLv3 |
| PyQt5-sip | BSD-2-Clause |
| Qt | LGPLv3/GPLv3 и лицензии сторонних частей |
| NumPy, SciPy, psutil | BSD и уведомления включённых библиотек |
| OpenCV / opencv-python | Apache-2.0 и уведомления зависимостей |
| FFmpeg | LGPL-2.1-or-later; включены сборочные рецепты и дополнительные notices |
| Pillow | MIT-CMU |
| pillow-heif | BSD-3-Clause для Python-обёртки |
| libheif, libde265 | LGPL-3.0-or-later |
| x265 | GPL-2.0-or-later; в этом комплекте используется совместно на условиях GPLv3 |
| pywin32 | PSF |
| PyInstaller | GPLv2 с исключением для bootloader |

PyQt доступен под GPLv3 либо коммерческой лицензией Riverbank; LGPL-варианта PyQt нет. Текущая сборка использует GPL-вариант. См. [официальные условия Riverbank](https://en.riverbankcomputing.com/software/pyqt). Выбор другой модели распространения требует отдельной проверки лицензий всей сборки.

Полная информация по нативным библиотекам и источникам — [third_party/README.txt](../third_party/README.txt). Нативные DLL использованы из upstream wheels; инструкции их самостоятельной сборки находятся в соответствующих исходных архивах.
