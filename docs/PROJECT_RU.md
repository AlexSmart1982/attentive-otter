# Attentive Otter для портфолио

**Создание собственного desktop-продукта для Windows и macOS. Автор продукта и алгоритма сравнения; разработка с применением ИИ.** Доступна Windows beta, порт macOS запланирован.

Создал приложение для поиска и разбора дубликатов и похожих изображений. Прошёл полный цикл создания продукта: от собственного алгоритма и требований до рабочего интерфейса, тестирования на реальных данных и подготовки автономной Windows-сборки.

- Разработал алгоритм сравнения изображений по содержимому, учитывающий повороты, изменение размера и повторное сжатие.
- Определял пользовательские сценарии, требования и приоритеты развития. Организовал разбор совпадений с просмотром метаданных, рекомендациями, отменой решений и сохранением прогресса.
- Совместно с ИИ-ассистентом выполнял настройку параметров алгоритма и доработку UI. ИИ использовался для реализации кода, тестов, рефакторинга, диагностики производительности, сборки и документации.
- По результатам реального использования выявлял проблемы производительности, формулировал задачи на исправление и проверял результат на тысячах групп.
- Подготовил beta-версию с контролируемым применением файловых действий, проверкой целостности и восстановлением прерванных операций. В проекте 174 автоматических теста.

Практическое использование: собственный архив из **84 000+ изображений и 5 365 групп похожих файлов**.

Технологии проекта: Python, PyQt5, OpenCV, NumPy, SciPy, SQLite, PyInstaller.

Автор алгоритма и продукта: **Скрябин Александр**.
